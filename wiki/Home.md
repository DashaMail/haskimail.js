# Haskimail Node.js

Добро пожаловать в документацию официальной Node.js библиотеки для [Haskimail API](https://haskimail.ru).

Библиотека `haskimail` предоставляет удобный типизированный интерфейс для работы со всеми возможностями API Haskimail: отправка транзакционных писем, управление шаблонами, доменами, вебхуками и многое другое.

## Быстрые ссылки

- [[Начало работы]] — установка и первое письмо
- [[Отправка писем]] — все способы отправки
- [[Шаблоны]] — работа с email-шаблонами
- [[Обработка ошибок]] — типизированные ошибки

## Клиенты

Библиотека предоставляет два клиента:

| Клиент | Токен | Назначение |
|---|---|---|
| `ServerClient` | `X-Haskimail-Server-Token` | Отправка писем, шаблоны, статистика, вебхуки |
| `AccountClient` | `X-Haskimail-Account-Token` | Управление серверами и доменами |
